# Мерило — расчёт мебели без ошибок

Приложение для мебельщика на телефоне: шкафы (прямые и угловые, распашные и купе),
кухни (нижние, верхние модули, пеналы), комоды и тумбы.

Считает деталировку с кромкой, раскладывает детали на листы ЛДСП, делает смету,
заказ на распил (текст и CSV) и коммерческое предложение для клиента.

Всё в одном файле `index.html`. `manifest.webmanifest` и `sw.js` делают его
устанавливаемым приложением (PWA), которое работает без интернета.
Данные хранятся на телефоне; резервная копия — в «Настройках».
