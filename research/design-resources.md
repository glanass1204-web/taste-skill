# Библиотека дизайн-ресурсов

Список из подборки «21 сайт для вайбкодера» (mike.mozg), с пометками, что подходит нашим проектам. Сохранено 5 ноября 2026.

Наши проекты: «Клуб 150», «Щит от мошенников», «Антимошенник» — простые HTML, CSS и JS без React. Поэтому ресурсы под React берём только как образец, код не тащим.

## Как пользоваться

1. Перед новым сайтом или редизайном смотрим 3–5 живых примеров (раздел «Подсмотреть дизайн») и записываем стиль в `DESIGN.md` проекта.
2. Готовый код берём, только если он на чистом CSS или JS и проходит наши правила: анимации 100–300 мс, только `transform` и `opacity`, уважение к `prefers-reduced-motion`, контраст по WCAG AA.
3. Лицензию проверяем у каждого ресурса перед использованием. Автора указываем, если лицензия этого требует.
4. Стекло, бесконечные декоративные анимации и «эффекты ради эффектов» не используем: это признаки шаблонного ИИ-дизайна.
