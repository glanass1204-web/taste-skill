- Владелец пишет по-русски, коротко, с телефона. Отвечать по-русски, просто, без технических подробностей.

## Что уже решено

- **Клуб 150.** Тяжёлые подходы (от 85%) округляются только вниз; блины 2,5 кг указываются в настройках. Разминка: суставная 5 минут (дорожки в зале нет), пустой гриф ×10, 50%×5, 70%×3, 85%×1. Советы Антитренера внесены: дольше отдых вместо снижения веса, на облегчённой неделе не добавлять, сон и белок, страхующий на тяжёлых неделях, растяжка 3 минуты после тренировки. В «Силе и рельефе» подход «+» до отказа только на тяжёлой неделе. Зал славы: 27 чемпионов, фото только со свободной лицензией и указанием автора. Открытые вопросы владельцу: подсказка про 95%×3 на 11-й неделе; второй лёгкий день жима.
- **Коды полной версии** (с 7 ноября 2026): подпись ECDSA P-256 номера телефона (`IC1|XXXX-XXXX`), в приложении только открытый ключ. ## Дизайн-правила

- Стиль каждого проекта — в его `DESIGN.md`. Источник стилей — Refero Styles, референсы — Minimal Gallery, Component Gallery (список: `research/design-resources.md`).
- Без стекла, без бесконечных декоративных анимаций, без «эффектов ради эффектов».
- Анимации: 100/150/200/300 мс, только `transform` и `opacity`, уважать `prefers-reduced-motion`.
- Проверять в браузере на 375, 768 и 1440 px и axe-core (WCAG 2 A/AA, цель — 0 нарушений).
- Проекты на чистом HTML/CSS/JS; библиотеки под React берём только как образец.
