# Винил·Лаб — измерения

`izmereniya.html` — отдельная страница измерений микрофоном для Винил·Лаб:

- скорость диска и детонация по тестовому тону 3150 Гц;
- АЧХ в комнате (третьоктавный анализатор + генератор розового шума);
- баланс каналов;
- уровень громкости.

Микрофон работает только на странице, открытой по `https://`. Самый простой способ — GitHub Pages:
Settings → Pages → Source: «Deploy from a branch» → ветка с этой папкой, папка `/ (root)`.
После публикации страница доступна по адресу
`https://<пользователь>.github.io/taste-skill/vinyl-lab/izmereniya.html`.

Звук обрабатывается только в браузере и никуда не отправляется.
