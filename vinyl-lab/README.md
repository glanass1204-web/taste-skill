# Винил·Лаб

Помощник винильщика: профиль системы, коллекция пластинок, список желаний, расстановка колонок,
калькуляторы настройки (резонанс, юстировка с протрактором 1:1, VTA, скорость, провода),
журнал износа иглы и измерения микрофоном.

- Сайт: https://glanass1204-web.github.io/taste-skill/vinyl-lab/ — можно установить на телефон как приложение.
- `vinyl-lab.zip` — офлайн-архив: распаковать и открыть `index.html`.
- `izmereniya.html` — измерения микрофоном (скорость и детонация, АЧХ комнаты, баланс, уровень).

Исходник основной страницы — `src/app.html` (та же страница, что и в claude.ai).
Сборка сайта, иконок, офлайн-режима и архива: `python3 src/build.py` (нужен Pillow).

Данные хранятся в браузере на устройстве; резервная копия — вкладка «Моя система».
